# Macdio — Press / Brand Kit

## Logo files
| File | Use |
|------|-----|
| `logo-dark.svg` / `logo-dark-1024.png` | Primary — on dark backgrounds |
| `logo-light.svg` / `logo-light-1024.png` | On light backgrounds |
| `glyph-white-transparent.svg` / `-1024.png` | White mark, transparent — over photos / dark UI |
| `glyph-ink-transparent.svg` / `-1024.png` | Dark mark, transparent — over light UI |

The mark is an audio **waveform** with a central **speaker** symbol (concentric ring + dot). It is a
speaker, not an eye — never restyle the center as an eye.

## Colors
See `COLORS.md`.

## Clear space & don'ts
- Keep clear space ≥ the height of the central speaker around the mark.
- Don't recolor the glyph outside the brand palette, rotate it, add outlines, or place the white glyph on
  light backgrounds (use the ink version instead).
- Don't stretch; scale proportionally. Minimum size ~24 px (the speaker must stay readable).
