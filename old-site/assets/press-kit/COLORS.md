# Macdio — Color Palette

| Role | Hex | Notes |
|------|-----|-------|
| Accent (primary) | `#5D81FF` | AccentColor asset (0.365 / 0.506 / 1.0). Buttons, selection, playing-station indicator, default artwork rings. |
| Macdio Blue (action) | `#0087FF` | Song ID buttons, match highlight. Most-used constant. |
| Light Blue (secondary) | `#3399FF` | Gradients, secondary accents. |
| Turquoise | `#00D9E6` | Wave / equalizer accents, tvOS glows. |
| Logo | Black `#000000` + White `#FFFFFF` | MacdioLogo asset — black field, white waveform + speaker. |

## Dark-glass icon background
Radial gradient `#3A424E → #1B2029 → #05070B` with a soft top light-pool (liquid-glass sheen).
