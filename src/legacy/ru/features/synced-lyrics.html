Функция

Каждое слово вовремя.

Радио не передаёт тексты песен. Macdio находит текст для песни, которая играет, и прокручивает его строка за строкой, с регулятором для тех нескольких секунд, на которые эфир расходится с текстом.

На 12 октября 2026 г. Macdio показывает синхронный текст песен для живого радио на iPhone, iPad, Mac и Apple TV. Как только песня известна, из названия от самой станции или через Song ID, Macdio загружает синхронизированный по времени текст из LRCLIB, открытой базы текстов песен, и подсвечивает строку, которую сейчас поют. Поскольку звук станции доходит до вас на несколько секунд позже её метаданных, тайминг можно двигать шагами по одной секунде, пока слова не лягут точно на голос. Если есть только обычный текст, он показывается без синхронизации.

Зачем живому радио сдвиг

Стриминговое приложение точно знает, в каком месте песни оно находится. Радиостанция этого не сообщает: название приходит по каналу метаданных, звук идёт через буфер, и между ними может быть несколько секунд в зависимости от станции и вашего соединения. Macdio запускает текст по времени метаданных песни и позволяет сдвинуть его двумя кнопками; сдвиг хранится для каждой станции, так что любимую станцию достаточно настроить один раз.

На каждом устройстве

На iPhone и iPad текст занимает весь плеер. На Mac он находится в панели рядом с экраном Сейчас играет. На Apple TV рядом с обложкой выезжает панель, которую удобно читать с дивана. Apple Watch показывает песню и обложку, но не текст.

Откуда берутся слова

LRCLIB это база текстов песен, которую ведёт сообщество, с синхронными таймингами для большой части популярной музыки и обычным текстом для остального. Macdio читает из неё и ничего в неё не записывает. Для песен, которых база не знает, текст не показывается вместо догадки.

Частые вопросы

Показывает ли Macdio тексты песен для радио?
Да. Синхронный прокручиваемый текст песни, которую играет станция, на iPhone, iPad, Mac и Apple TV.
Почему текст расходится на несколько секунд?
Звук эфира приходит позже его метаданных. Подвиньте сдвиг шагами по одной секунде; Macdio запомнит его для каждой станции.
Для каких песен есть текст?
Для тех, что знает база LRCLIB. Популярная музыка покрыта хорошо; для песни без записи текст не показывается.
Работает ли это на станциях без названий песен?
Да, как только Song ID назовёт песню. Текст подбирается по распознанному названию.
Работает ли это на Apple Watch?
Нет. Часы показывают песню и обложку; текст есть на iPhone, iPad, Mac и Apple TV.
