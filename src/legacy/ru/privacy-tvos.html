Конфиденциальность на Apple TV.

Как tvOS-версия Macdio обращается с вашей информацией в гостиной. Последнее обновление: 11 октября 2026 г.

Все платформы
iOS macOS tvOS watchOS

Обзор

Macdio для Apple TV создан с заботой о вашей конфиденциальности. Я не собираю, не храню и не передаю никакие личные данные. Эта политика конфиденциальности объясняет, как tvOS-версия Приложения обращается с вашей информацией.

Сбор данных

Macdio не собирает никакой личной информации. Все ваши данные синхронизируются только через ваш личный аккаунт iCloud.

Я не использую никаких SDK для аналитики, рекламы или отслеживания.

Данные об использовании (ярлык конфиденциальности)

Macdio собирает «Другие данные об использовании» для цели «Функциональность приложения». Речь о вашей истории прослушивания: какие станции вы слушали, как долго и на каком устройстве.

Эти данные:

  • не связаны с вашей личностью
  • не используются для отслеживания
  • хранятся только в вашем личном контейнере iCloud
  • используются исключительно для показа вашей личной статистики прослушивания на ваших устройствах

Особенности tvOS

Macdio на Apple TV не поддерживает запись. Приложение только воспроизводит потоки и не хранит на вашем устройстве никаких аудиофайлов. Данные для Top Shelf обрабатываются локально, чтобы показывать станции, которые вы недавно слушали.

Сторонние сервисы

Для основных функций Macdio подключается к следующим сервисам:

  • Radio Browser API для просмотра станций. Личные данные не передаются.
  • dir.macdio.app, собственная копия каталога станций Macdio, к которой приложение обращается, только когда Radio Browser не отвечает. Она хранит только суточные итоги. Личные данные не передаются.
  • LRCLIB для загрузки текстов песен. Личные данные не передаются.
  • iTunes Search API для загрузки обложек. Личные данные не передаются.
  • Logo.dev предоставляет логотипы радиостанций, у которых нет собственного логотипа. Передаётся только веб-домен станции, без личных данных.
  • Podcast Index для поиска подкастов, чартов и категорий. Передаётся только поисковый запрос или категория. Выпуски и ленты загружаются напрямую с собственного сервера каждого подкаста.
  • Apple ShazamKit для Song ID. В сервис Shazam от Apple уходит короткая звуковая сигнатура потока, а не запись. Микрофон никогда не используется.

Синхронизация iCloud

Ваше избранное, история прослушивания и настройки синхронизируются через ваш личный контейнер iCloud, которым управляет Apple.

Подробнее читайте в Политике конфиденциальности Apple.
