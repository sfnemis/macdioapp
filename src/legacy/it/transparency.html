Come è fatto Macdio.

Macdio è un progetto di una persona sola. Ecco uno sguardo onesto su come funziona l'app, quali dati tocca e cosa c'è dietro il suo sviluppo.

Chi sviluppa Macdio

Macdio è il progetto di un solo sviluppatore, Sait Firat NEMIS. Non c'è un'azienda dietro, nessun team, nessun investitore. Solo una persona che costruisce l'app radio che mancava sull'App Store.

Mi occupo del codice SwiftUI su tutte e sei le piattaforme, del sito, della presenza sull'App Store e della casella del supporto. Se scrivi a support@macdio.app, arrivi direttamente a me.

Come è fatto

Macdio è al 100% Swift e SwiftUI nativi. Niente Electron, niente React Native, niente web view. Ogni schermata è scritta apposta per la piattaforma su cui gira: iPhone, iPad, Mac, Apple TV, Apple Watch e CarPlay.

Come la maggior parte degli sviluppatori nel 2026, uso strumenti moderni di assistenza basati sull'AI nel mio lavoro, per esplorare casi limite, provare idee e venire a capo di sessioni di debug complicate. Ma l'architettura di base, le scelte di design, l'ottimizzazione delle prestazioni e il codice che arriva davvero nell'app nascono da ricerca ragionata e da tanti tentativi fatti con le mie mani. Ci tengo a curare i dettagli, e questo vuol dire capire ogni livello del sistema invece di accettare quello che uno strumento genera.

Fonti di dati e API

Macdio non cura un suo catalogo di stazioni. L'elenco delle stazioni arriva da Radio Browser, un database pubblico della comunità, con la copia gestita da Macdio (dir.macdio.app) usata solo quando Radio Browser non risponde. I metadati di ciò che è in riproduzione e i testi arrivano da API pubbliche. Ecco con cosa parla l'app:

Radio Browser

Database di stazioni radio internet curato dalla comunità. Fornisce i metadati delle stazioni, gli URL degli stream, le informazioni sul paese e i tag di genere. È da qui che arriva il catalogo di decine di migliaia di stazioni.

radio-browser.info ↗

iTunes Search API

L'API di ricerca pubblica di Apple, usata per arricchire le informazioni su ciò che è in riproduzione con copertina, anno di uscita e nome dell'album, a partire dai metadati del brano che le stazioni trasmettono.

iTunes Search API ↗

LRCLIB

API di testi open source e gratuita. Fornisce testi sincronizzati (in formato LRC) e testi semplici per la canzone in riproduzione. Nessuna chiave API richiesta, nessun tracciamento.

Dipendenze

Macdio ha pochissime dipendenze. L'app non usa nessun pacchetto Swift di terze parti. È costruita interamente con i framework di Apple (SwiftUI, SwiftData, AVFoundation, CloudKit, MediaPlayer).

Anche questo sito è altrettanto leggero. Non carica font web né librerie 3D. Il testo usa il font di sistema già presente sul tuo dispositivo Apple, e ogni animazione è semplice CSS e JavaScript. I servizi esterni sono:
