Confidentialité à votre poignet.

Comment la version watchOS de Macdio traite vos informations sur Apple Watch. Dernière mise à jour le 11 octobre 2026.

Toutes les plateformes
iOS macOS tvOS watchOS

Vue d'ensemble

Macdio pour Apple Watch est conçu en pensant à votre vie privée. Je ne collecte, ne stocke et ne partage aucune donnée personnelle.

Collecte de données

Macdio ne collecte aucune information personnelle. Toutes les données ne se synchronisent que par votre compte iCloud personnel.

Je n'utilise aucun SDK d'analyse, de publicité ou de pistage.

Données d'utilisation (étiquette de confidentialité)

Macdio collecte Autres données d'utilisation pour Fonctionnalités de l'app. Il s'agit de votre historique d'écoute : quelles stations vous avez écoutées, combien de temps, et sur quel appareil.

Ces données sont :

  • Non liées à votre identité
  • Non utilisées pour le pistage
  • Stockées uniquement dans votre conteneur iCloud privé
  • Utilisées seulement pour afficher vos statistiques d'écoute personnelles sur vos appareils

Particularités de watchOS

Macdio sur Apple Watch ne prend pas en charge l'enregistrement ni la surveillance de l'espace disque. L'app diffuse l'audio et affiche les informations de la station.

Services tiers

Macdio se connecte aux services suivants pour ses fonctions de base :

  • API Radio Browser pour parcourir les stations. Aucune donnée personnelle n'est envoyée.
  • dir.macdio.app, la copie de l'annuaire de stations tenue par Macdio, utilisée seulement quand Radio Browser ne répond pas. Elle ne garde que des totaux quotidiens. Aucune donnée personnelle n'est envoyée.
  • iTunes Search API pour récupérer les pochettes. Aucune donnée personnelle n'est envoyée.
  • Logo.dev fournit les logos des stations de radio qui n'en proposent pas elles-mêmes. Seul le domaine web de la station est envoyé, aucune donnée personnelle.

Synchronisation iCloud

Vos favoris, votre historique d'écoute et vos réglages se synchronisent via votre conteneur iCloud privé géré par Apple.

Consultez la politique de confidentialité d'Apple.
