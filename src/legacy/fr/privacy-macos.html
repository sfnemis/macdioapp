Confidentialité sur votre Mac.

Comment la version macOS de Macdio traite vos informations, à l'intérieur de l'App Sandbox. Dernière mise à jour le 11 octobre 2026.

Vue d'ensemble

Macdio pour macOS est conçu en pensant à votre vie privée. Je ne collecte, ne stocke et ne partage aucune donnée personnelle. Cette politique de confidentialité explique comment la version Mac de l'App traite vos informations.

Collecte de données

Macdio ne collecte aucune information personnelle. Toutes vos données restent sur votre appareil et ne se synchronisent que par votre compte iCloud personnel.

Je n'utilise aucun SDK d'analyse, de publicité ou de pistage.

Données d'utilisation (étiquette de confidentialité)

Comme déclaré dans l'étiquette de confidentialité de l'App Store, Macdio collecte Autres données d'utilisation pour Fonctionnalités de l'app. Il s'agit de votre historique d'écoute : quelles stations vous avez écoutées, combien de temps, et sur quel appareil.

Ces données sont :

  • Non liées à votre identité
  • Non utilisées pour le pistage
  • Stockées uniquement dans votre conteneur iCloud privé
  • Utilisées seulement pour afficher vos statistiques d'écoute personnelles sur vos appareils

App Sandbox

Macdio tourne dans l'App Sandbox de macOS avec les autorisations dont ses fonctions ont besoin : l'accès réseau pour le streaming et pour le relais local qui garde les flux stables, iCloud pour la synchronisation, les notifications pour les nouveaux épisodes, les Apple Events pour envoyer les surlignages vers Apple Notes quand vous le demandez, et le Private Cloud Compute d'Apple pour les résumés d'épisodes. Il n'a aucun accès au micro. Il ne lit ou n'écrit que les fichiers que vous choisissez vous-même, comme un fichier OPML ou une liste de stations, et ne peut atteindre ni les contacts ni les autres apps.

Services tiers

Macdio se connecte aux services externes suivants uniquement pour ses fonctions de base :

  • API Radio Browser pour parcourir et rechercher des stations de radio. Aucune donnée personnelle n'est envoyée.
  • dir.macdio.app, la copie de l'annuaire de stations tenue par Macdio, utilisée seulement quand Radio Browser ne répond pas. Elle ne garde que des totaux quotidiens. Aucune donnée personnelle n'est envoyée.
  • LRCLIB pour récupérer les paroles synchronisées. Aucune donnée personnelle n'est envoyée.
  • iTunes Search API pour récupérer les pochettes d'album. Aucune donnée personnelle n'est envoyée.
  • Logo.dev fournit les logos des stations de radio qui n'en proposent pas elles-mêmes. Seul le domaine web de la station est envoyé, aucune donnée personnelle.
  • Podcast Index pour la recherche de podcasts, les classements et les catégories. Seul le terme recherché ou la catégorie est envoyé. Les épisodes et les flux se téléchargent directement depuis le serveur de chaque émission.
  • Apple ShazamKit pour Song ID. Une courte signature audio du flux, pas un enregistrement, part vers le service Shazam d'Apple. Le micro n'est jamais utilisé.
  • Le modèle de langage d'Apple écrit les chapitres et le résumé d'un épisode de podcast, sur l'appareil ou sur le Private Cloud Compute d'Apple, qui ne garde pas le texte.
  • push.macdio.app, le serveur de notifications de Macdio, reçoit l'adresse de notification de ce Mac et les émissions que vous suivez, seulement tant que Notifications de nouveaux épisodes est activé. Il ne garde rien d'autre.

Synchronisation iCloud

Vos favoris, stations sauvegardées, historique d'écoute et réglages sont stockés dans votre conteneur iCloud privé géré par Apple.

Consultez la politique de confidentialité d'Apple.

Audio & enregistrements

Les enregistrements sont stockés localement sur votre Mac. Je n'envoie, ne transmets ni ne consulte vos enregistrements.
