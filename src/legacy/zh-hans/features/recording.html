功能

录下电台，得到一个曲库。

直接从网络捕获任何直播流，不用麦克风，没有房间里的杂音。按曲目分割会给你每首歌一个文件，每个都有名字，每段录音里的歌曲也都列出来。

截至 2026年10月12日，Macdio 可以在 iPhone、iPad 和 Mac 上录制直播电台。录音直接取自流本身，所以不用麦克风，也没有环境噪音。按曲目分割利用电台自己的歌曲边界，把一次录音切成每首歌一个文件，并设有最短时长保护，所以电台更正一次歌名不会把一首歌切成两半。之后 Song ID 引擎会扫描完成的录音，列出其中的歌曲和时间点。格式有原始流、MP3、AAC 或 M4A，可选原始音质，或 128、192、256 kbps。

一次录音怎么变成一首首曲目

在电台播放时按下录音。Macdio 把流写进文件，同时盯着电台的元数据，等一首歌结束、下一首开始的那一刻。打开按曲目分割后，每到一个边界就关闭当前文件、打开下一个，并以歌名命名。不发送歌名的电台会录成一个文件，之后由 Song ID 给里面的歌曲命名。

限制，说清楚

  • 录音在 iPhone、iPad 和 Mac 上可用。Apple TV 和 Apple Watch 能播放，但不能录音。
  • 录音默认在三小时后自动停止；最长时长可以修改。没有在指定时间自动开始的定时录音。
  • 剩余空间不足 500 MB 时不会开始录音，所以永远不会把设备塞满。
  • 录音留在应用里。没有导出、共享表单、隔空投送，也不能复制到“文件”；这是和 App 审核团队一起做出的决定，不会改变。

格式和音质

“原始”完全按广播的样子保留流，对 AAC 或 MP3 电台来说就是最好的副本。想要更小的文件，或者某个播放器偏好的格式时，MP3、AAC 和 M4A 会以 128、192 或 256 kbps 重新编码。FLAC 和 Ogg 流在“原始”模式下按原样保留。

这样做合法吗？

为自己收听而录下广播，和磁带录音机几十年来做的事一样，在大多数国家，个人使用没有问题。共享或出售录音则不行，这也是 Macdio 把录音留在应用里的原因。录音指南逐个国家讲了相关法律。

常见问题

Macdio 能录制网络电台吗？
能，在 iPhone、iPad 和 Mac 上，直接从流录制，不用麦克风。按曲目分割会为每首歌生成一个带名字的文件。
能定时录音吗？
不能。录音需要手动开始，到达你设定的最长时长后停止，默认三小时。
能导出或共享录音吗？
不能。录音留在应用里，这是有意的设计，也是和 App 审核团队达成的约定。
用什么格式录音？
原始流、MP3、AAC 或 M4A，可选原始音质，或 128、192、256 kbps。
在 Apple TV 或 Apple Watch 上能录音吗？
不能。这两个版本能播放电台，但不能录音。
