Privacidad en el Apple TV.

Cómo trata tu información la versión de Macdio para tvOS en el salón. Última actualización: 11 de octubre de 2026.

Todas las plataformas
iOS macOS tvOS watchOS

Resumen

Macdio para Apple TV está diseñada pensando en tu privacidad. No recojo, almaceno ni comparto ningún dato personal. Esta política de privacidad explica cómo trata tu información la versión de la app para tvOS.

Recogida de datos

Macdio no recoge ninguna información personal. Todos tus datos se sincronizan únicamente a través de tu cuenta personal de iCloud.

No uso ningún SDK de analítica, publicidad o rastreo.

Datos de uso (etiqueta de privacidad)

Macdio recoge Otros datos de uso para la Funcionalidad de la app. Se refiere a tu historial de escucha: qué emisoras has reproducido, durante cuánto tiempo y en qué dispositivo.

Estos datos:

  • No están vinculados a tu identidad
  • No se usan para rastreo
  • Se almacenan solo en tu contenedor privado de iCloud
  • Se usan únicamente para mostrar tus estadísticas de escucha personales en tus dispositivos

Particularidades de tvOS

Macdio en el Apple TV no admite grabación. La app solo reproduce en streaming y no almacena ningún archivo de audio en tu dispositivo. Los datos de Top Shelf se procesan localmente para mostrar tus emisoras reproducidas recientemente.

Servicios de terceros

Macdio se conecta a los siguientes servicios para su funcionalidad básica:

  • API de Radio Browser para explorar emisoras. No se envía ningún dato personal.
  • dir.macdio.app, la copia propia de Macdio del directorio de emisoras, usada solo cuando Radio Browser no responde. Guarda únicamente totales diarios. No se envía ningún dato personal.
  • LRCLIB para obtener letras. No se envía ningún dato personal.
  • API de búsqueda de iTunes para obtener carátulas. No se envía ningún dato personal.
  • Logo.dev proporciona los logotipos de las emisoras de radio que no ofrecen uno propio. Solo se envía el dominio web de la emisora, ningún dato personal.
  • Podcast Index para la búsqueda, las listas de éxitos y las categorías de podcasts. Solo se envía el término de búsqueda o la categoría. Los episodios y los feeds se descargan directamente del servidor de cada programa.
  • Apple ShazamKit para Song ID. Al servicio Shazam de Apple llega una breve firma de audio del stream, no una grabación. El micrófono no se usa nunca.

Sincronización con iCloud

Tus favoritos, tu historial de escucha y tus ajustes se sincronizan a través de tu contenedor privado de iCloud, gestionado por Apple.
