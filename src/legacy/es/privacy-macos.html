Privacidad en tu Mac.

Cómo trata tu información la versión de Macdio para macOS, dentro del App Sandbox. Última actualización: 11 de octubre de 2026.

Todas las plataformas
iOS macOS tvOS watchOS

Resumen

Macdio para macOS está diseñada pensando en tu privacidad. No recojo, almaceno ni comparto ningún dato personal. Esta política de privacidad explica cómo trata tu información la versión de la app para Mac.

Recogida de datos

Macdio no recoge ninguna información personal. Todos tus datos se quedan en tu dispositivo y se sincronizan únicamente a través de tu cuenta personal de iCloud.

No uso ningún SDK de analítica, publicidad o rastreo.

Datos de uso (etiqueta de privacidad)

Tal como se declara en la etiqueta de privacidad del App Store, Macdio recoge Otros datos de uso para la Funcionalidad de la app. Se refiere a tu historial de escucha: qué emisoras has reproducido, durante cuánto tiempo y en qué dispositivo.

Estos datos:

  • No están vinculados a tu identidad
  • No se usan para rastreo
  • Se almacenan solo en tu contenedor privado de iCloud
  • Se usan únicamente para mostrar tus estadísticas de escucha personales en tus dispositivos

App Sandbox

Macdio se ejecuta dentro del App Sandbox de macOS con los permisos mínimos: acceso a la red para el streaming, micrófono para la grabación e iCloud para la sincronización. No puede acceder a archivos, contactos ni otras apps sin tu permiso explícito.

Servicios de terceros

Macdio se conecta a los siguientes servicios externos únicamente para su funcionalidad básica:

  • API de Radio Browser para explorar y buscar emisoras de radio. No se envía ningún dato personal.
  • dir.macdio.app, la copia propia de Macdio del directorio de emisoras, usada solo cuando Radio Browser no responde. Guarda únicamente totales diarios. No se envía ningún dato personal.
  • LRCLIB para obtener letras sincronizadas. No se envía ningún dato personal.
  • API de búsqueda de iTunes para obtener carátulas de álbumes. No se envía ningún dato personal.
  • Logo.dev proporciona los logotipos de las emisoras de radio que no ofrecen uno propio. Solo se envía el dominio web de la emisora, ningún dato personal.

Sincronización con iCloud

Tus favoritos, emisoras guardadas, historial de escucha y ajustes se almacenan en tu contenedor privado de iCloud, gestionado por Apple.

Consulta la política de privacidad de Apple.

Audio y grabaciones

Las grabaciones se almacenan localmente en tu Mac. No subo, transmito ni accedo a tus grabaciones.
