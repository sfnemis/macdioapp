誰在打造 Macdio

Macdio 是 Sait Firat NEMIS 的獨立開發者專案。背後沒有公司、沒有團隊、沒有投資人。就是一個人，在做一款 App Store 上感覺缺少的電台 App。

六個平台的 SwiftUI 程式碼、網站、App Store 頁面和支援信箱，全部由我處理。寫信到 support@devdio.pro，就是直接找到我。

它是怎麼做的

Macdio 是 100% 原生的 Swift 和 SwiftUI。沒有 Electron、沒有 React Native、沒有網頁視圖。每個畫面都是專為它所運行的平台而寫：iPhone、iPad、Mac、Apple TV、Apple Watch 和 CarPlay。

和 2026 年大多數開發者一樣，我在工作流程中使用現代的 AI 輔助工具，用來探索邊界情況、製作原型，以及處理棘手的除錯過程。但核心架構、設計決策、效能調校和最終出貨的程式碼，全都來自審慎的研究和親手反覆打磨。我在意把細節做對，這表示要理解技術堆疊的每一層，而不是接受工具產生的任何東西。

資料來源與 API

Macdio 不自行編製電台目錄。電台列表來自 Radio Browser，一個由社群維護的公開資料庫；只有在 Radio Browser 沒有回應時，才會使用 Macdio 自己的副本（dir.macdio.app）。正在播放的中繼資料和歌詞來自公開 API。以下是 App 會連線的對象：

Radio Browser

由社群維護的網路電台資料庫。提供電台中繼資料、串流網址、國家資訊和類型標籤。數萬個電台的目錄就來自這裡。

radio-browser.info ↗

iTunes Search API

Apple 的公開搜尋 API，用來根據電台廣播的曲目中繼資料，抓取專輯封面、發行年份和專輯名稱，豐富正在播放的資訊。

iTunes Search API ↗

LRCLIB

開放原始碼的免費歌詞 API。為目前播放的歌曲提供同步（LRC 格式）和純文字歌詞。不需要 API 金鑰，沒有追蹤。

lrclib.net ↗

Podcast Index

開放、獨立的 Podcast 索引，收錄 470 萬個 Podcast。負責 Podcast 搜尋、排行榜和分類。集數和 feed 接著直接從各節目自己的伺服器下載。

podcastindex.org ↗

Apple ShazamKit

Apple 的歌曲辨識。Song ID 送出的是串流的一小段音訊特徵，從來不是錄音，也從不用麥克風，拿回來的是歌名、演出者和封面。

ShazamKit ↗

push.macdio.app

Macdio 自己的新集數通知伺服器。只有在你開啟通知時，它才會收到裝置的通知位址和你追蹤的節目，除此之外什麼都沒有。

隱私權政策

相依套件

Macdio 的相依套件極少。App 本身使用零個第三方 Swift 套件，完全以 Apple 自己的框架打造（SwiftUI、SwiftData、AVFoundation、CloudKit、MediaPlayer）。

這個網站同樣精簡。沒有網頁字體，沒有 3D 函式庫。字體使用你 Apple 裝置上已有的系統字體，每個動畫都是純 CSS 和 JavaScript。外部服務如下：

名稱用途類型
Umami 不使用 Cookie、不涉及個人資料的造訪計數（僅網站） 網站
Radio Browser 目錄頁面的電台資料，由你的瀏覽器直接查詢（僅網站） 網站
dir.macdio.app Macdio 自己保存的 Radio Browser 目錄副本。目錄頁面只在 Radio Browser 沒有回應時才會詢問它。它不保留 IP 位址。 網站
hub.devdio.pro Macdio 自己的社群論壇。標誌上的「New」徽章會向本網站自己的伺服器詢問最新的三則版本說明；你的瀏覽器從不連線到論壇，唯一保留的是你上次看過的最後一篇文章 id，存在瀏覽器的本機儲存空間裡。 網站
