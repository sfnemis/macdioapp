作り方

Macdioは100%ネイティブのSwiftとSwiftUIです。Electronも、React Nativeも、ウェブビューもありません。どの画面も、それが動くプラットフォームのために書いています。iPhone、iPad、Mac、Apple TV、Apple Watch、そしてCarPlayです。

2026年のほとんどの開発者と同じように、私も作業の一部で最新のAI支援ツールを使っています。エッジケースを調べたり、アイデアの試作をしたり、厄介なデバッグを進めたりするためです。それでも、中心となるアーキテクチャ、デザインの判断、パフォーマンスの調整、そして最終的に出荷するコードは、すべて意図的な調査と手を動かしての反復から生まれています。細部を正しくすることにこだわっていて、それはツールが生成したものをそのまま受け入れるのではなく、スタックのすべての層を理解するということです。

データソースとAPI

Macdioは独自の局カタログを編集していません。局の一覧は公開のコミュニティデータベースであるRadio Browserから取得し、Macdio独自のコピー（dir.macdio.app）はRadio Browserが応答しないときにだけ使います。再生中のメタデータと歌詞は公開APIから取得します。アプリが通信する相手は次のとおりです。

Radio Browser

コミュニティが管理するインターネットラジオ局のデータベース。局のメタデータ、ストリームURL、国の情報、ジャンルのタグを提供します。何万もの局のカタログはここから来ています。

radio-browser.info ↗

iTunes Search API

Appleの公開検索APIです。ラジオ局が放送する曲のメタデータをもとに、アルバムアートワーク、リリース年、アルバム名を取得して、再生中の情報を充実させるために使います。

iTunes Search API ↗

LRCLIB

オープンソースで無料の歌詞API。再生中の曲について、同期歌詞（LRC形式）とプレーンテキストの歌詞を提供します。APIキーは不要で、トラッキングもありません。

lrclib.net ↗

Podcast Index

470万のポッドキャストを収めた、オープンで独立したインデックス。ポッドキャストの検索、チャート、カテゴリを支えています。エピソードとフィードは、そのあと各番組のサーバーから直接ダウンロードされます。

podcastindex.org ↗

Apple ShazamKit

Appleの曲認識。Song IDはストリームの短い音声シグネチャを送り、録音もマイクも決して使わずに、曲、アーティスト、カバーを受け取ります。

ShazamKit ↗

push.macdio.app

新しいエピソードのための、Macdio独自の通知サーバー。通知をオンにしたときだけ、デバイスの通知アドレスとあなたがフォローしている番組を受け取り、それ以外は何も受け取りません。

プライバシーポリシー

依存関係

Macdioの依存関係は最小限です。アプリ自体はサードパーティのSwiftパッケージを1つも使っていません。すべてAppleのフレームワーク（SwiftUI、SwiftData、AVFoundation、CloudKit、MediaPlayer）で作られています。

このウェブサイトも同じくらい身軽です。ウェブフォントも3Dライブラリもありません。文字はAppleデバイスにすでに入っているシステムフォントを使い、アニメーションはすべて素のCSSとJavaScriptです。外部サービスは次のとおりです。
