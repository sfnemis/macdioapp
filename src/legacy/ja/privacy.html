全体の概要

Macdio（以下「本アプリ」）は、開発者Sait Firat NEMISが一人で作っています。このページはすべてのプラットフォームを対象としています。上のリンクに各プラットフォームの詳細があります。

データの収集

お気に入りの局、保存した曲、録音、ポッドキャストの購読、再生の進み具合、文字起こし、ハイライトはあなたのデバイス上にとどまります。それらはあなた自身のiCloudアカウントを通じてのみ同期されます。Macdioにはアカウントの仕組みがなく、あなたを特定する手段もありません。

新しいエピソードの通知（iPhone）

新しいエピソードの通知がオンで通知を許可すると、iPhoneはMacdioの通知サーバー（push.macdio.app、Cloudflare上で動作）に2つのものを送ります。Appleがこのデバイスに割り当てた通知アドレスと、フォローしている番組のフィードアドレスです。サーバーはそれらのフィードを確認します。新しいエピソードが現れると、Appleに通知の配信を依頼するので、アプリが閉じていても通知が届きます。

サーバーはそれ以外を何も保持しません。名前も、アカウントも、IPアドレスも、リスニング履歴もありません。このデータはあなたに紐付けられず、トラッキングには使われません。通知をオフにすると、デバイスはすぐにサーバーから削除されます。サーバーはまた、Appleが無効になったと報告したアドレスを削除し、30日間確認のなかったデバイスを削除します。

ポッドキャスト

ポッドキャストの検索、チャート、カテゴリはPodcast IndexとAppleのポッドキャストチャートから取得されます。エピソード、アートワーク、フィードは各番組自身のサーバーから直接ダウンロードされます。文字起こしはあなたのデバイス上で作られ、音声がアップロードされることはありません。

チャプターと要約はAppleの言語モデルによって、デバイス上またはAppleのPrivate Cloud Compute上で書かれます。Private Cloud ComputeはAppleを含む誰にもテキストが保存されず、読めないようにAppleが設計したものです。

ハイライトをNotionやReadwiseに送るとき、それはあなたが入力したアクセストークンを使って、あなたのデバイスからそのサービスへ直接送られます。トークンはキーチェーンに保管されます。iCloudキーチェーンがオンなら、Appleがエンドツーエンドの暗号化でほかのデバイスに同期し、Macdioがトークンを送るのはそのサービスだけです。Apple Notes、Obsidian、Craft、Bearは、あなたのデバイス上のそれぞれのアプリを通じてハイライトを受け取ります。

サードパーティのサービス

Macdioは、機能を提供するためだけに次のサービスに接続します。

  • Radio Browser API: ラジオ局のブラウズと検索のため。
  • Macdio独自の局ディレクトリ（dir.macdio.app）: Radio Browserディレクトリのコピーで、Cloudflareと開発者自身のサーバー上で動きます。MacdioはRadio Browserが応答しないときだけこれを使います。Radio Browserが受け取るのと同じリクエストに加えて、アプリのプラットフォームとバージョンを受け取ります。保持するのは日ごとの合計だけです。何人のリスナーがそれを必要とし、いくつのリクエストに応答したか。IPアドレスも識別子も保存しません。
  • LRCLIB: 再生中の曲の同期歌詞のため。
  • iTunes Search API: アルバムアートワークとトラックの詳細のため。
  • Logo.dev: 自身でロゴを提供しない局のロゴのため。送られるのは局のウェブドメインだけです。
  • Apple ShazamKit: Song IDのため。録音ではなく、ストリームの短い音声シグネチャが、曲を探すためにAppleのShazamサービスに送られます。マイクが使われることはありません。
  • Podcast Index: ポッドキャストの検索、チャート、カテゴリのため。

各サービスはリクエストに必要なもの、たとえば曲名や検索語だけを受け取ります。あなたやあなたのデバイスの識別子は送られません。

iCloud同期

iCloud同期を使う場合、ライブラリ、ポッドキャストの進み具合、ハイライト、設定はAppleが管理するあなたのプライベートなiCloudコンテナに保存されます。Macdioの開発者はこのデータを見ることができません。Appleの慣行についてはAppleのプライバシーポリシーをご覧ください。

音声と録音

Macdioで作った録音はあなたのデバイス上にとどまります。アップロードや共有は一切されません。

このウェブサイト

macdio.appは、訪問を区別するためにCookieを設定するGoogle Analyticsと、Cookieを設定しないCloudflare Web Analyticsで訪問数を数えています。局ディレクトリのページはあなたのブラウザからRadio Browserに接続し、「新着」バッジは最新のリリースノートをこのサイト自身のサーバーに問い合わせます。透明性のページにすべてのサービスを載せています。

子どものプライバシー

Macdioは、13歳未満の子どもを含め、誰からも意図的に個人データを収集しません。上記の通知データは個人的なものではなく、誰にも紐付けられません。
