Transparência

Como o Macdio é feito.

O Macdio é um projeto solo. Aqui está um olhar honesto sobre como o app funciona, que dados ele toca e o que entra na sua construção.

Quem faz o Macdio

O Macdio é um projeto de um só desenvolvedor, Sait Firat NEMIS. Não há empresa por trás, nem equipe, nem investidores. Só uma pessoa construindo o app de rádio que parecia faltar na App Store.

Eu cuido do código SwiftUI nas seis plataformas, do site, da presença na App Store e da caixa de entrada do suporte. Se você escrever para support@devdio.pro, está falando diretamente comigo.

Como ele é feito

O Macdio é 100% Swift e SwiftUI nativos. Sem Electron, sem React Native, sem web views. Cada tela é escrita especificamente para a plataforma em que roda: iPhone, iPad, Mac, Apple TV, Apple Watch e CarPlay.

Como a maioria dos desenvolvedores em 2026, eu uso ferramentas modernas assistidas por IA como parte do meu fluxo de trabalho, para explorar casos extremos, prototipar ideias e atravessar sessões difíceis de depuração. Mas a arquitetura central, as decisões de design, o ajuste de desempenho e o código final que vai para a loja vêm todos de pesquisa deliberada e iteração na prática. Eu me importo em acertar os detalhes, e isso significa entender cada camada da pilha em vez de aceitar o que uma ferramenta gera.

Fontes de dados & APIs

O Macdio não monta um catálogo próprio de estações. As listas de estações vêm do Radio Browser, um banco de dados público mantido pela comunidade, e a cópia própria do Macdio (dir.macdio.app) só é usada quando o Radio Browser não responde. Os metadados do que está tocando e as letras vêm de APIs públicas. Veja com o que o app conversa:

Radio Browser

Banco de dados de estações de rádio pela internet mantido pela comunidade. Fornece metadados das estações, URLs de stream, informações de país e tags de gênero. É daqui que vem o catálogo de dezenas de milhares de estações.

radio-browser.info ↗

iTunes Search API

A API pública de busca da Apple, usada para enriquecer a informação do que está tocando buscando a capa do álbum, o ano de lançamento e o nome do álbum a partir dos metadados da faixa que as estações de rádio transmitem.

iTunes Search API ↗

LRCLIB

API de letras gratuita e de código aberto. Fornece letras sincronizadas (formato LRC) e em texto simples para a música que está tocando. Sem chave de API, sem rastreamento.

lrclib.net ↗

Podcast Index

Índice aberto e independente de 4,7 milhões de podcasts. Alimenta a busca, as paradas e as categorias de podcasts. Episódios e feeds depois são baixados direto do servidor de cada programa.

podcastindex.org ↗

Apple ShazamKit

O reconhecimento de músicas da Apple. O Song ID envia uma assinatura de áudio curta do stream, nunca uma gravação e nunca o microfone, e recebe de volta a música, o artista e a capa.

ShazamKit ↗

push.macdio.app

O próprio servidor de notificações do Macdio para novos episódios. Só quando você ativa as notificações ele recebe o endereço de notificação do aparelho e os programas que você segue, e mais nada.

Política de privacidade

Dependências

O Macdio tem uma pegada mínima de dependências. O app em si usa zero pacotes Swift de terceiros. É construído inteiramente com os frameworks da própria Apple (SwiftUI, SwiftData, AVFoundation, CloudKit, MediaPlayer).

Este site é igualmente enxuto. Ele vem sem fontes web e sem bibliotecas 3D. A tipografia usa a fonte do sistema que já está no seu aparelho Apple, e toda animação é CSS e JavaScript puros. Os serviços externos são:

Servidores de logos das estações Na página do diretório, o logo de cada estação é carregado do servidor da própria estação, então esses servidores veem o seu endereço IP. As requisições são enviadas sem referrer, e um logo que não carrega é substituído por um glifo local. Nada passa por este site. Web
