Privacidade no seu Mac.

Como a versão para macOS do Macdio trata as suas informações, dentro do App Sandbox. Última atualização em 11 de outubro de 2026.

Todas as plataformas
iOS macOS tvOS watchOS

Visão geral

O Macdio para macOS é projetado com a sua privacidade em mente. Eu não coleto, armazeno nem compartilho nenhum dado pessoal. Esta política de privacidade explica como a versão para Mac do App trata as suas informações.

Coleta de dados

O Macdio não coleta nenhuma informação pessoal. Todos os seus dados ficam no seu aparelho e sincronizam apenas pela sua conta pessoal do iCloud.

Eu não uso nenhum SDK de análise, publicidade ou rastreamento.

Dados de uso (rótulo de privacidade)

Conforme declarado no rótulo de privacidade da App Store, o Macdio coleta Outros dados de uso para Funcionalidade do app. Isso se refere ao seu histórico de escuta, quais estações você tocou, por quanto tempo e em qual aparelho.

Esses dados são:

  • Não vinculados à sua identidade
  • Não usados para rastreamento
  • Armazenados apenas no seu contêiner privado do iCloud
  • Usados unicamente para mostrar suas estatísticas pessoais de escuta entre aparelhos

App Sandbox

O Macdio roda dentro do App Sandbox do macOS com as permissões de que os recursos precisam: acesso à rede para streaming e para o relay local que mantém os streams estáveis, iCloud para sincronização, notificações para novos episódios, Apple Events para enviar destaques ao Apple Notes quando você pede, e o Private Cloud Compute da Apple para os resumos de episódios. Ele não tem acesso ao microfone. Só lê ou grava os arquivos que você mesmo escolhe, como um arquivo OPML ou uma lista de estações, e não consegue chegar aos contatos nem a outros apps.

Serviços de terceiros

O Macdio se conecta aos seguintes serviços externos unicamente para a funcionalidade principal:

  • API do Radio Browser para navegar e buscar estações de rádio. Nenhum dado pessoal é enviado.
  • dir.macdio.app, a cópia própria do Macdio do diretório de estações, usada somente quando o Radio Browser não responde. Ela guarda apenas totais diários. Nenhum dado pessoal é enviado.
  • LRCLIB para buscar letras sincronizadas. Nenhum dado pessoal é enviado.
  • iTunes Search API para buscar capas de álbuns. Nenhum dado pessoal é enviado.
  • Logo.dev fornece os logos das estações de rádio que não oferecem um. Só o domínio web da estação é enviado, nenhum dado pessoal.
  • Podcast Index para busca, paradas e categorias de podcasts. Só o termo de busca ou a categoria é enviado. Episódios e feeds são baixados direto do servidor de cada programa.
  • Apple ShazamKit para o Song ID. Uma assinatura de áudio curta do stream, não uma gravação, vai para o serviço Shazam da Apple. O microfone nunca é usado.
  • O modelo de linguagem da Apple escreve os capítulos e o resumo de um episódio de podcast, no aparelho ou no Private Cloud Compute da Apple, que não guarda o texto.
  • push.macdio.app, o servidor de notificações do Macdio, recebe o endereço de notificação deste Mac e os programas que você segue, só enquanto Notificações de Novos Episódios estiver ativado. Ele não guarda mais nada.

Sincronização pelo iCloud

Seus favoritos, estações salvas, histórico de escuta e configurações ficam armazenados no seu contêiner privado do iCloud, administrado pela Apple.

Consulte a Política de Privacidade da Apple.

Áudio & gravações

As gravações ficam armazenadas localmente no seu Mac. Eu não envio, transmito nem acesso as suas gravações.
