Is a radio station missing from Macdio? Add it to Radio Browser and it will show up in the app.

Macdio gets its stations from Radio Browser, a free directory that anyone can add to. Macdio reads it directly, so a station added there also appears in Macdio, usually within minutes of Radio Browser accepting it.
  1. Check whether the station is already in the station directory.
  2. If it is not there, add it on Radio Browser.

    Add a station on Radio Browser

  3. To listen right away, paste the stream URL into Macdio under Library, then Add Custom Station.

Questions about a listing? Write to support@macdio.app.
