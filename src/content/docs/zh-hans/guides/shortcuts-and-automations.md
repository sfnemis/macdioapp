Macdio 在 iPhone、iPad 和 Mac 上为 Apple 的“快捷指令”App 添加了九个操作。用它们，你可以在自己的快捷指令和自动化里开始播放一个电台、播放你的收藏、停止电台或者播放一集播客，比如让一个电台在工作日早上 7:00 自己开始播放。Apple TV 和 Apple Watch 没有 Macdio 操作。

## 快速步骤

在 iPhone 或 iPad 上，让一个电台每天早上在设定的时间开始播放：

1. 打开“快捷指令”App，进入“自动化”。
2. 新建一个个人自动化，选择“特定时间”触发条件。
3. 设定时间和日期，并让它立即运行。
4. 添加一个操作，搜索 Macdio，选择“播放电台”。
5. 轻点“电台”，选择你的电台，然后存储。

自动化的这些界面属于 Apple 的“快捷指令”App，而不是 Macdio，所以措辞在不同的 iOS 版本之间可能略有不同。Macdio 的部分（“播放电台”和它的“电台”字段）始终是上面这些名字。

## “快捷指令”App 里的每一个 Macdio 操作

| 操作 | 你要选择什么 | 它做什么 | 会打开 Macdio |
|---|---|---|---|
| “播放电台” | “电台” | 播放那个电台。 | 是 |
| “播放收藏” | 无 | 按你自己的收藏顺序，开始播放第一个电台。你的其他收藏变成“下一个”和“上一个”在其中移动的列表。 | 是 |
| “继续播放电台” | 无 | 继续播放暂停的电台或剧集。如果没有暂停的内容，它会播放你最近听过的那个，上次的电台或上次听到一半的剧集。如果你从来没播放过任何东西，它会按名称开始播放你的第一个收藏。 | 是 |
| “停止广播” | 无 | 停止电台。剧集会暂停并保留位置。 | 否 |
| “打开播客” | “播客” | 在 Macdio 里打开那个节目的页面。 | 是 |
| “播放最新单集” | “播客” | 播放那个节目最新的一集。 | 否 |
| “继续播放播客” | 无 | 继续播放你上次听的那一集。 | 否 |
| “播放“接下来播放”列表” | 无 | 播放“接下来播放”里的第一项。 | 否 |
| “标记此刻” | 无 | 把正在播放的剧集的当前这一秒保存为一条高亮，连同转写文本里的那句话。 | 否 |

标为“否”的操作在后台运行。“播放最新单集”、“继续播放播客”和“播放“接下来播放”列表”播放音频时不会把 Macdio 带到前台，所以适合那些不应该占用屏幕的自动化。关于高亮的更多内容在 [播客转写文本和高亮](/guides/podcast-transcripts-and-highlights.html)里。

## 电台选择器怎样找到你的电台

你在“播放电台”里轻点“电台”时，Macdio 最多会推荐 20 个电台：先是你的收藏，按 A 到 Z 排列，然后是你最近播放过的电台。每个电台还会把它简短的口语名称显示为单独的行，全名在下面，所以“BBC Radio 1”、“BBC 1”和“BBC One”可能都会出现。它们播放的都是同一个电台。

在选择器里输入文字，会按名称搜索你 Macdio 资料库里的每一个电台，最多显示 20 个匹配项。你的资料库指的是你的收藏、你自己添加的电台和你播放过的电台。你从没打开过的目录电台还不在里面，所以先播放一次，或者先把它设为收藏。如果你需要一个根本不在目录里的流，参见 [怎样添加自定义电台](/guides/add-a-custom-station.html)。

“打开播客”和“播放最新单集”里的“播客”选择器列出你订阅的节目，同样会把简称作为额外的行。

## 三个值得设置的自动化

### 开始你的早晨电台

按照上面的快速步骤操作。如果你用“播放收藏”代替“播放电台”，你的其余收藏会排在第一个后面，在 AirPods 上按两下就会切换到下一个收藏。[AirPods 和耳机控制指南](/guides/airpods-and-headphone-controls.html)解释了这个列表是怎样工作的。

一天的另一头，再建一个带“停止广播”的“特定时间”自动化，就能在午夜停止电台，而且不会打开应用。Macdio 自己的睡眠定时器在播放器里做同样的事，参见 [睡眠定时器和时钟模式](/guides/sleep-timer-and-clock-mode.html)。

### 专注模式打开时播放一个电台

“快捷指令”App 可以在某个专注模式打开或关闭时运行自动化。这个触发条件是 Apple 的，所以要在个人自动化的触发条件列表里找它。选择你的“工作”专注模式，设为在专注模式打开时运行，然后添加“播放电台”，选上你喜欢边工作边听的电台。再建一个在专注模式关闭时运行、带“停止广播”的自动化，就能把它关掉。

### 每天早上听某个节目的最新一集

创建一个“特定时间”自动化，添加“播放最新单集”，然后选择节目。它会播放这个节目最新的完整一集，不会打开 Macdio。如果订阅源上次检查是一个多小时以前，Macdio 会先刷新它，但只等大约 6 秒。如果刷新时间更长，它就播放它已经知道的最新一集。只能选择你订阅的节目；[Macdio 中的播客](/guides/podcasts-in-macdio.html)讲了怎样订阅。

## 在 Mac 上能用吗？

能。同样的九个操作也出现在 Mac 的“快捷指令”App 里，它们控制 Mac 的播放器。你可以把它们放进你在那里建的任何快捷指令。

## Siri 指令在哪里？

上面的每一个操作也能响应语音指令，比如“在 Macdio 中播放 [电台]”或“停止Macdio”。完整的列表，以及它们能用的语言，在 [Siri 指南](/guides/siri-radio.html)里。

## 值得了解的限制

- Apple TV 和 Apple Watch 上没有 Macdio 操作。
- 只能选择你资料库里的电台。如果你之后删除了一个电台，播放它的已存快捷指令就再也找不到它了，所以要重新选择电台。
- “标记此刻”需要一集正在播放、而且有转写文本的剧集。否则它会回答“没有正在播放的单集。”或“这一集还没有文字稿，因此没有可标记的句子。”
- 应用刚启动时，操作可能会回答“Macdio 仍在启动。请稍后再试。”
- 自动化在什么时候、以什么方式运行，比如在 iPhone 锁定时，是由 iOS 决定的。在你看着的时候先试运行一次新的自动化，这样你就知道它会按你预期的方式开始。

## 常见问题

### “快捷指令”App 里有哪些 Macdio 操作？

九个：“播放电台”、“播放收藏”、“继续播放电台”、“停止广播”、“打开播客”、“播放最新单集”、“继续播放播客”、“播放“接下来播放”列表”和“标记此刻”。它们在 iPhone、iPad 和 Mac 上都有。

### Macdio 能每天早上自动开始播放一个电台吗？

能。在“快捷指令”App 里创建一个“特定时间”自动化，添加 Macdio 的“播放电台”操作，然后选择电台。它会在你设定的时间运行。

### 快捷指令能在设定的时间停止 Macdio 吗？

能。在一个“特定时间”自动化里使用“停止广播”操作。它运行时不会打开应用。电台会停止，剧集会暂停并保留位置。

### 为什么我的电台不在快捷指令的电台选择器里？

选择器只认识存在你 Macdio 资料库里的电台：收藏、你自己添加的电台和你播放过的电台。先播放一次这个电台，或者把它设为收藏，然后在选择器里输入它的名字。

### 为什么选择器把同一个电台列出了不止一次？

每一个简短的口语名称都有自己的一行，所以 BBC Radio 1 也可能显示为 BBC 1 和 BBC One。这些行播放的都是同一个电台。

### Macdio 的快捷指令在 Apple TV 或 Apple Watch 上能用吗？

不能。这些操作只在 iPhone、iPad 和 Mac 上有。Apple TV 和 Apple Watch 没有 Macdio 操作。
