在 iPhone、iPad 和 Mac 上，你可以用流地址把任何网络电台添加到 Macdio。在“资料库”里轻点“+”，选择“添加自定义电台”（在 Mac 上是“添加电台…”），粘贴 URL，给电台起个名字，然后添加。Macdio 在保存之前会检查这个地址是否真的在发送音频，之后电台会通过 iCloud 同步到你的其他设备，包括 Apple TV。

目录里有 60,000 多个电台，但仍然会漏掉一些，往往是小型的本地电台。如果你还没有地址，[如何找到电台的流地址](/guides/find-radio-stream-url.html)告诉你去哪里找。

## 快速步骤

在 iPhone 或 iPad 上：

1. 打开“资料库”，轻点“+”。
2. 选择“添加自定义电台”。
3. 把地址粘贴到“流地址或电台网站”里。
4. 轻点“扫描”确认这个流并填好名字，或者自己输入“电台名称”。
5. 轻点“添加”。

## 每台设备上的添加按钮在哪里？

| 设备 | 在哪里找到 | 保存用的按钮 |
|---|---|---|
| iPhone 和 iPad | “资料库”、“+”、“添加自定义电台”，或者“设置”、“自定义电台”、“添加自定义电台” | “添加” |
| Mac | “资料库”、“+”、“添加电台…” | “添加电台” |
| Apple TV | “设置”、“在电脑上编辑”，然后在同一个 Wi-Fi 上用浏览器 | 浏览器里的“Save” |
| Apple Watch 和 CarPlay | 没有添加表单。它们播放你资料库里的电台 | |

在 iPhone 上，“设置”在“更多”里，除非你把它移进了标签栏。

## 怎样在 iPhone 或 iPad 上添加电台

在“自定义电台”面板里，“扫描”（或换行键）会检查你在“流地址或电台网站”里输入的内容。如果是一个流，它会被确认，空着的名字也会被填上。如果是一个网站，你会得到上面的流的列表，每个都带一个音质菜单和一个“使用”按钮。“标志”、“国家/地区”和用逗号分隔的“标签”都是可选的。一切正常时，“测试流媒体 URL”会回答“流媒体可访问！”。名字或地址为空，或者测试或扫描还在进行时，“添加”保持灰色。

## 怎样在 Mac 上添加电台

在“资料库”里，点“+”并选择“添加电台…”。“添加自定义电台”面板里有“电台名称”、带“扫描”按钮的“流媒体 URL”、“电台标志”、“国家或地区（可选）”和“标签（用逗号分隔，可选）”。一旦你输入了地址，就会出现“测试流媒体”，正常的流会报告“Stream is reachable”，以及它的编码格式和码率。点“添加电台”或按换行键。

## 哪些流 URL 能在 Macdio 中使用？

- 以 http 或 https 开头的地址。如果不写开头，Macdio 会先试“https://”，再试普通的“http://”。
- 直接的 MP3 和 AAC 流。
- HLS 流：以 .m3u8 结尾的地址，或者用 HLS 播放列表应答的服务器。
- 以 .pls、.m3u、.asx 或 .xspf 结尾的播放列表链接。Macdio 会打开播放列表，使用其中的第一个流。
- SHOUTcast 服务器，包括用“ICY 200 OK”应答的老服务器。

长度固定的文件，比如一集播客或一段台标音乐，不会被当成电台接受。

## 轻点“添加”时 Macdio 会检查什么

不可能是地址的内容会得到“Invalid URL format. Please check the URL.”。名字和地址都相同的第二个电台会得到“A station with this name and URL already exists.”。

然后 Macdio 会询问服务器，最多等 6 秒。如果地址是一个网站，什么都不会保存，扫描会开始运行，让你从它的流中选一个。如果连不上服务器，你会看到原因和“Tap Add again to save it anyway.”（在 Mac 上是“Click Add again to save it anyway.”）。再点一次就会保存。

新电台会出现在“我的电台”下面。只有你给它加了星标，它才会成为收藏（参见 [收藏、列表和同步](/guides/favorites-lists-and-sync.html)）。

## 怎样给自定义电台设置标志

“标志”控件（在 Mac 上是“电台标志”）有四个选项：

- “自动”会按名字和地址在 Logo.dev 上查找这个电台。
- “链接”接受一个指向图片文件的直接链接，就是你用“复制图片地址”得到的那种，以 .png 或 .jpg 结尾。如果你粘贴的是一个带有标志的网页，Macdio 能找到图片时会换成那张图片。
- “我的图像”使用你自己的图片：在 iPhone 和 iPad 上是“照片”或“文件”（iCloud 云盘也可以），在 Mac 上是“选择图像…”。它和电台一起保存，所以会显示在你的所有设备上。
- “无”会使用 Macdio 自己的图案。

以后想改，在 iPhone 或 iPad 上长按电台，或者在 Mac 上右键点按它，然后选择“电台标志…”。这对目录里的电台也有效，可以用“自动”、“我的图像”和“无”。“链接”只用于你自己添加的电台。

## 怎样编辑或删除自定义电台

在 iPhone 和 iPad 上，长按电台并选择“编辑电台”，或者在它那一行向右轻扫，轻点“编辑”。改好需要改的地方，轻点“保存”。要删除它，在“我的电台”里那一行向左轻扫，轻点“移除”，再用“删除”确认。确认提示会说明，这个电台会从每一台设备和它所在的每一个列表中消失。

在 Mac 上，右键点按电台，选择“编辑电台”（然后“存储更改”）或“删除电台”，删除也会先问一句。

保存编辑时不会测试修改过的地址，所以先用测试按钮。目录里的电台不能编辑，但“重命名…”（iPhone 和 iPad）和“重命名电台…”（Mac）可以给它们起你自己的名字，“重置名称”会把原来的名字找回来。

## 在 Apple TV 上添加电台

电视上没有添加表单。在它的“设置”里启动“在电脑上编辑”，连着同一个 Wi-Fi 的电脑上的浏览器就会得到一张你自己电台的表格，包括标志 URL（[分步说明](/guides/edit-stations-on-computer.html)）。不管怎样，在 iPhone、iPad 或 Mac 上添加的电台都会通过 iCloud 到达电视。

## 值得了解的限制

- 添加电台需要网络连接，因为检查、扫描和查找标志都要联网。
- 扫描一个网站可能需要一分钟，有些网站把播放器藏得太好，一个流都找不到。
- iPhone 和 iPad 上不能从文件导入电台列表。一次添加很多电台时，用 [浏览器编辑器](/guides/edit-stations-on-computer.html)里的导入。
- 自定义电台成为收藏或最近播放过之后，CarPlay 和 [Siri](/guides/siri-radio.html) 才能找到它。CarPlay 也会在你的列表里显示它。

## 常见问题

### Macdio 接受哪些流地址？

任何 http 或 https 的电台流：MP3、AAC、HLS（.m3u8）、以 .pls、.m3u、.asx 或 .xspf 结尾的播放列表链接，以及老式的 SHOUTcast 服务器。播客剧集不会被当成电台。

### 如果我只知道电台的网站怎么办？

把网站粘贴到地址栏里，然后用“扫描”。Macdio 会列出它在那里找到的流，每个都带一个音质菜单，你从中选一个。

### 为什么 Macdio 会说“Tap Add again to save it anyway”？

Macdio 检查地址时连不上这个流。再点一次就会照样保存这个电台，如果电台只是暂时停播，这样很有用。

### 我的自定义电台会出现在我的其他设备上吗？

会。它们通过 iCloud 同步到你的 Mac、iPhone、iPad 和 Apple TV，Apple Watch 则从 iPhone 获取。

### 能给自定义电台设置自己的标志吗？

能。选择“自动”、“链接”（一个图片地址）、“我的图像”（一张来自“照片”或“文件”的图片）或“无”。你自己的图片会显示在你的所有设备上。
