“在电脑上编辑”让你在同一个 Wi-Fi 下的任何一台电脑上，用浏览器和真正的键盘管理你自己添加的电台。你在 iPhone、iPad 或 Apple TV 上的 Macdio 设置里启动它，打开它显示的地址，输入 6 位代码，就会得到一张表格，可以在里面添加、编辑、排序、导入和导出你的电台。没有任何东西经过服务器。浏览器只和你的设备通信。

Mac 上没有这个功能。在 Mac 上，你用“添加电台…”添加电台，用右键点按来编辑，参见 [添加自定义电台](/guides/add-a-custom-station.html)。

## 快速步骤

1. 在 iPhone 或 iPad 上，打开“设置”、“自定义电台”、“在电脑上编辑”。在 Apple TV 上，打开“设置”，找到“在电脑上编辑”卡片，选择“打开”。
2. 启动编辑器：iPhone 和 iPad 上是“启动编辑器”，Apple TV 上也是“启动编辑器”。
3. 在电脑的浏览器里输入设备上显示的地址。
4. 输入 6 位代码。
5. 做好修改，点“Save”。

## 怎样在 iPhone 或 iPad 上启动编辑器

前往“设置”、“自定义电台”、“在电脑上编辑”（在 iPhone 上，“设置”在“更多”里，除非你把它移进了标签栏），轻点“启动编辑器”。第一次使用时，iOS 会问 Macdio 能否查找你本地网络上的设备。请允许，否则浏览器连不上 iPhone 或 iPad。

运行起来之后，“就绪”部分会显示“在你的电脑上打开”和地址，以及“然后输入此代码”和代码，代码在你轻点“显示”之前以圆点隐藏。“停止编辑器”会结束它。

## 怎样在 Apple TV 上启动编辑器

打开“设置”，找到“在电脑上编辑”卡片（“我的电台编辑器”），选择“打开”。在“在电脑上编辑”界面里，按“启动编辑器”。

电视会显示“打开此地址”和大号字体的地址，以及“然后输入此代码”和 6 位数字，始终可见。“停止编辑器”、“完成”或“菜单”按钮会关闭它。如果无法启动，会提供“重试”。

## 在浏览器里能做什么？

这个页面只有英文，所以下面引用的按钮名称保留英文。地址是一个普通的 http 地址，由设备的 Wi-Fi 地址和一个端口号组成。每次启动都会重新选择端口，所以地址可能和上次不同，代码也是每次启动都更新。

页面首先会要代码。代码错了会显示“That code did not work. Check the code on your device.”

之后你会看到带数量的“My Stations”，还有“Reload”和“Save”。工具栏上有一个筛选框（按名称、地址或标签）、“Add station”、“Scan a website”、“Import”、“Export”，以及一个按名称给表格排序的按钮。列依次是星标、Name、Stream URL、Logo URL、Country 和 Tags。

每一行都有一个拖动手柄、一个把电台设为收藏的星标、用来查找标志的“Logo”、请你的设备检查这个流能否播放的“Test”，以及删除这一行的“✕”。在小屏幕上，上下箭头代替拖动。两行使用同一个地址时，页面会用“Another row uses this same address”标出它们。

“Scan a website”使用和应用相同的查找器：它会列出电台网站上的每一个频道，带一个音质选择器，“Add selected”会把它们放进表格。

行的顺序就是应用里“我的电台”的顺序。在你点“Save”之前，没有任何东西会到达你的设备，之后状态会显示“Saved to device”。从那里开始，修改会通过 iCloud 同步到你的其他设备。

## 怎样从 JSON、CSV 或 M3U 导入电台

“Import”接受你粘贴进去的文本：

- JSON：一个电台列表，每个电台有“name”和“streamURL”，还可以有“logoURL”、“country”和“tags”。
- CSV：一行表头 `name,stream,logo,country,tags,favorite`，然后每行一个电台。
- M3U：一行带电台名称的 `#EXTINF:-1,`，后面跟着流地址。

“Fill with a JSON example”、“Fill with a CSV example”和“Fill with an M3U example”这几个按钮会在框里放一个能用的示例。这是 M3U 的那个：

```
#EXTM3U
#EXTINF:-1,Radio Paradise
https://stream.radioparadise.com/aac-320
```

“Add to list”会把这些行加进表格。你点“Save”时，它们才会到达设备。

## 怎样导出你的电台

“Export”在一个界面里把你的电台显示为 JSON、CSV 和 M3U，并提供“JSON file”、“CSV file”和“M3U file”。下载的文件名是 macdio-stations.json、macdio-stations.csv 和 macdio-stations.m3u。

## “Save”会对你的电台列表做什么

“Save”会用页面里的表格替换你的自定义电台列表。你的设备保留你看到的这些行，删除表格里没有的每一个你自己的电台，iCloud 会把这个删除带到每一台设备上。实际来说：

- 你用“✕”删掉的一行，保存时会在每一台设备上被删除，页面不会先问你。
- 如果这个页面载入之后，你在另一台设备上添加或修改过电台，编辑前先点“Reload”。从旧页面保存会把旧表格放回去。
- 保留每一行的地址，并以 http:// 或 https:// 开头。地址为空或缺少这个开头的行，在“Save”时会被丢掉，它所属的电台也会被删除。浏览器不会像应用那样替你加上“https://”。

## 编辑器什么时候停止？

它只在你保持打开时运行。你按下停止、离开编辑器界面、Macdio 进入后台，或者你关闭浏览器标签页时，它就会停止。浏览器 2 分钟没有动静、5 分钟内没有浏览器连接，或者输错 5 次代码之后，它也会停止。运行期间，手机或电视的屏幕会保持常亮。

## 值得了解的限制

- 两台设备必须在同一个网络上。
- 表格最多容纳 500 个电台，一次只能运行一个网站扫描。
- 目录里的电台和你的列表不在编辑器里。请在应用里修改它们，参见 [收藏、列表和同步](/guides/favorites-lists-and-sync.html)。
- 这个页面的 JSON 和 Mac 上“导出电台…”的 JSON 是不同的格式。各自用它自己的导入功能读回去。

## 常见问题

### 哪些设备有“在电脑上编辑”？

iPhone、iPad 和 Apple TV。Mac 本来就有键盘，直接在应用里编辑电台。Apple Watch 和 CarPlay 没有这个功能。

### 为什么我的电脑打不开那个地址？

两台设备必须在同一个 Wi-Fi 上，编辑器界面必须保持打开，而且在 iPhone 和 iPad 上 Macdio 需要本地网络权限。每次启动时地址都可能变化。

### 编辑器会修改目录里的电台吗？

不会。浏览器里只出现你自己添加的电台，目录里的电台永远不会被修改。

### 能导入一个 M3U 电台播放列表吗？

能。把播放列表的文本粘贴到“Import”里，点“Add to list”，然后点“Save”。“Import”也接受 JSON 和 CSV。

### 在共用的 Wi-Fi 上用编辑器安全吗？

它需要一个每次启动都会更新的 6 位代码，输错 5 次就会关闭，而且只在编辑器界面打开时运行。连接是你网络内部的普通 http。

### 我在浏览器里删掉的电台会怎样？

一旦你点了“Save”，它就会在每一台设备上被删除。“Save”会用页面里的表格替换你的自定义电台列表，所以如果你在别处改过电台，先重新载入页面。
