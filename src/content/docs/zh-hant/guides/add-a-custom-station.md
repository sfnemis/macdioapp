在 iPhone、iPad 和 Mac 上，你可以用串流位址把任何網路電台加入 Macdio。在「資料庫」裡點「+」，選「新增自訂電台」（在 Mac 上是「加入電台…」），貼上網址，替電台命名，然後加入。Macdio 會在儲存前確認這個位址真的送出音訊，電台接著會透過 iCloud 同步到你的其他裝置，Apple TV 也包括在內。

電台目錄有 60,000 多個電台，還是會漏掉一些，常常是小型的地方電台。如果你還沒有位址，[如何找到電台的串流網址](/guides/find-radio-stream-url.html)會告訴你該去哪裡找。

## 快速步驟

在 iPhone 或 iPad 上：

1. 打開「資料庫」，點「+」。
2. 選「新增自訂電台」。
3. 把位址貼到「串流位址或電台網站」。
4. 點「掃描」確認串流並填入名稱，或自己輸入「電台名稱」。
5. 點「新增」。

## 每部裝置上的新增按鈕在哪裡？

| 裝置 | 在哪裡找 | 儲存的按鈕 |
|---|---|---|
| iPhone 和 iPad | 「資料庫」、「+」、「新增自訂電台」，或「設定」、「自訂電台」、「新增自訂電台」 | 「新增」 |
| Mac | 「資料庫」、「+」、「加入電台…」 | 「新增電台」 |
| Apple TV | 「設定」、「在電腦上編輯」，然後在同一個 Wi-Fi 上使用瀏覽器 | 瀏覽器裡的「Save」 |
| Apple Watch 和 CarPlay | 沒有新增表單。它們播放你資料庫裡的電台 | |

在 iPhone 上，「設定」放在「更多」裡，除非你把它移進了標籤列。

## 如何在 iPhone 或 iPad 上加入電台

在「自訂電台」面板裡，「掃描」（或 Return 鍵）會檢查你在「串流位址或電台網站」裡輸入的內容。串流會被確認，空白的名稱會被填入。網站則會得到一份它上面的串流清單，每個都有品質選單和「使用」按鈕。「標誌」、「國家/地區」和用逗號分隔的「標籤」是選填的。一切正常時，「測試串流 URL」會回答「串流可連線！」。名稱或位址是空的，或測試、掃描正在執行時，「新增」會保持灰色。

## 如何在 Mac 上加入電台

在「資料庫」裡，按「+」並選擇「加入電台…」。「新增自訂電台」面板有「電台名稱」、附「掃描」按鈕的「串流 URL」、「電台標誌」、「國家或地區（選填）」和「標籤（用逗號分隔，選填）」。輸入位址後，「測試串流」就會出現，正常的串流會回報「Stream is reachable」（串流可連線），以及它的編碼格式和位元率。按「新增電台」或 Return 鍵。

## 哪些串流網址能在 Macdio 中使用？

- 以 http 或 https 開頭的位址。如果省略開頭，Macdio 會先試「https://」，再試一般的「http://」。
- 直接的 MP3 和 AAC 串流。
- HLS 串流：以 .m3u8 結尾的位址，或以 HLS 播放列表回應的伺服器。
- 以 .pls、.m3u、.asx 或 .xspf 結尾的播放列表連結。Macdio 會打開播放列表，使用裡面的第一個串流。
- SHOUTcast 伺服器，包括回應「ICY 200 OK」的舊伺服器。

長度固定的檔案，例如 Podcast 單集或廣告歌，不會被接受為電台。

## 點「新增」時 Macdio 檢查什麼

不可能是位址的東西會得到「Invalid URL format. Please check the URL.」（網址格式無效）。名稱和位址都相同的第二個電台會得到「A station with this name and URL already exists.」（已有名稱和網址都相同的電台）。這些訊息在 App 裡是英文。

接著 Macdio 會詢問伺服器，最多等 6 秒。如果位址是網站，什麼都不會儲存，掃描會執行，讓你從它的串流裡挑一個。如果連不到伺服器，你會看到原因，以及「Tap Add again to save it anyway.」（在 Mac 上是「Click Add again to save it anyway.」），意思是再按一次「新增」就照樣儲存。再點一下就會儲存。

新電台會出現在「我的電台」底下。只有你替它加星號時，它才會變成收藏（請看[收藏、清單和同步](/guides/favorites-lists-and-sync.html)）。

## 如何替自訂電台加上標誌

「標誌」控制項（在 Mac 上是「電台標誌」）有四個選擇：

- 「自動」會依電台的名稱和位址在 Logo.dev 上尋找。
- 「連結」接受直接指向圖片檔的連結，也就是用「拷貝影像位址」得到的那種，以 .png 或 .jpg 結尾。如果你貼上的是帶有標誌的網頁，Macdio 找得到圖片時會換成那張圖片。
- 「我的影像」使用你自己的圖片：在 iPhone 和 iPad 上是「照片」或「檔案」（iCloud 雲碟也可以），在 Mac 上是「選擇影像…」。它和電台一起儲存，所以會顯示在你所有的裝置上。
- 「無」會畫出 Macdio 自己的圖案。

之後想更改，在 iPhone 或 iPad 上長按電台，或在 Mac 上按右鍵，然後選「電台標誌…」。這對目錄裡的電台也有用，可以選「自動」、「我的影像」和「無」。「連結」只適用於你自己加入的電台。

## 如何編輯或刪除自訂電台

在 iPhone 和 iPad 上，長按電台並選「編輯電台」，或在它那一列向右滑並點「編輯」。改好需要改的地方，點「儲存」。要刪除它，在「我的電台」裡的那一列向左滑，點「移除」，再用「刪除」確認。確認訊息會說明這個電台會從每部裝置、以及它所在的每個清單中移除。

在 Mac 上，在電台上按右鍵，選「編輯電台」（然後按「儲存更動」）或「刪除電台」，刪除也會先詢問。

儲存編輯時不會測試改過的位址，所以請先用測試按鈕。目錄裡的電台無法編輯，但「重新命名…」（iPhone 和 iPad）和「重新命名電台…」（Mac）可以給它們你自己取的名稱，「重置名稱」則會帶回原本的名稱。

## 在 Apple TV 上加入電台

電視沒有新增表單。在它的「設定」裡啟動「在電腦上編輯」，同一個 Wi-Fi 上電腦的瀏覽器就會拿到一張你自己電台的表格，包括標誌網址（[逐步說明](/guides/edit-stations-on-computer.html)）。在 iPhone、iPad 或 Mac 上加入的電台，無論如何都會透過 iCloud 送到電視。

## 值得知道的限制

- 加入電台需要網路連線，因為檢查、掃描和尋找標誌都要上網。
- 掃描網站最多可能要一分鐘，有些網站把播放器藏得太好，找不到任何串流。
- iPhone 和 iPad 沒有匯入電台清單檔案的功能。一次要加很多電台時，請用[瀏覽器編輯器](/guides/edit-stations-on-computer.html)裡的匯入。
- CarPlay 和 [Siri](/guides/siri-radio.html) 會在自訂電台成為收藏、或是你最近播放過的電台之後找到它。CarPlay 也會在你的清單裡顯示它。

## 常見問題

### Macdio 接受哪些串流位址？

任何 http 或 https 的電台串流：MP3、AAC、HLS（.m3u8）、以 .pls、.m3u、.asx 或 .xspf 結尾的播放列表連結，以及舊的 SHOUTcast 伺服器。Podcast 單集不會被當成電台。

### 如果我只知道電台的網站呢？

把網站貼到位址欄位，然後使用「掃描」。Macdio 會列出它在那裡找到的串流，每個都有品質選單，由你挑一個。

### 為什麼 Macdio 顯示「Tap Add again to save it anyway」？

Macdio 檢查位址時連不到那個串流。再點一下就會照樣儲存電台，當電台只是暫時停播時很有用。

### 我的自訂電台會出現在其他裝置上嗎？

會。它們透過 iCloud 同步到你的 Mac、iPhone、iPad 和 Apple TV，Apple Watch 則從 iPhone 取得。

### 能給自訂電台一個自己的標誌嗎？

可以。選「自動」、「連結」（圖片位址）、「我的影像」（來自「照片」或「檔案」的圖片）或「無」。你自己的圖片會顯示在你所有的裝置上。
