四種有效的方法，按我會嘗試的順序排列，加上你喜愛的串流突然安靜時該怎麼辦。

電台的串流網址是它音訊的直接網址，有四種可靠的方法可以取得：電台自己的收聽頁面、開放的社群目錄、瀏覽器開發者工具的 Network 分頁，以及直接問電台。下面按值得嘗試的順序排列，還有一個原本能用的網址安靜下來時該怎麼辦。

## 串流網址是什麼

它是音訊來源的直接網址，而不是包著它的網頁。有些以 .mp3、.aac 或 .m3u8 這類副檔名結尾，有些只是一個主機加連接埠。貼進播放器，電台就開始播放，中間沒有任何網站。

## 1. 電台自己的網站

從這裡開始，因為這是源頭。許多電台會發布一個收聽或調台頁面，提供 .m3u 或 .pls 檔案，常標示為給 VLC、Winamp 或「其他播放器」用。那些小檔案是播放列表，裡面包含真正的串流網址，任何像樣的播放器都能直接讀取。

## 2. 開放的社群目錄

由社群維護的資料庫收集聽眾提交、並自動檢查的串流網址。大多數電台 App，包括 Macdio，都是從這裡取得目錄，當一個電台的網站很難瀏覽或使用你看不懂的語言時，這通常是最快的方法。拿到網址之後，[如何在 Mac 上收聽網路電台](/guides/how-to-listen-to-radio-on-mac.html)說明該把它貼到哪裡。

## 3. 瀏覽器開發者工具

如果電台只提供網頁播放器，網址還是看得到。打開播放器頁面，打開瀏覽器的開發者工具，選 Network 分頁，篩選為 Media，然後按播放。那個持續執行、不斷變大的請求就是串流。在上面按右鍵，複製網址。

## 4. 問電台

被低估、但往往最快的方法。小電台會回電子郵件，很多還很高興有人想好好地聽。當一個電台有好幾種不同品質的來源時，這也省去猜測的麻煩。

## 關於你可以用它做什麼

找到一個公開的串流網址並自己收聽，是普通的收聽行為。轉發電台的音訊、重新播送，或圍繞別人的來源建立服務，就是另一回事，有自己的授權義務。保持個人、保持簡單：把你自己的播放器指向電台，好好享受。

## 串流安靜下來的時候

電台搬伺服器的頻率比大家預期的高。失效的網址很少代表電台真的關了，所以放棄前先重新查一次電台；通常會有新網址，更新自訂電台比刪掉它划算。

## 常見問題

### 什麼是電台串流網址？

它是電台音訊來源的直接網址，而不是包著它的網頁。有些以 .mp3、.aac 或 .m3u8 結尾，有些只是一個主機加連接埠，播放器不經任何網站就能直接打開。

### 如何找到電台的串流網址？

先試電台自己的收聽頁面，再試開放的社群目錄，然後在網頁播放器執行時看瀏覽器開發者工具的 Network 分頁。都不行的話，寫信問電台。

### 為什麼串流網址會失效？

電台更換伺服器的頻率比聽眾想的高。失效的網址通常代表串流搬家了，而不是電台關了，所以重新查一次電台，更新網址而不是刪掉它。
