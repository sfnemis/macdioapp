「在電腦上編輯」讓你在同一個 Wi-Fi 上任何一台電腦的瀏覽器裡，用真正的鍵盤管理你自己加入的電台。你在 iPhone、iPad 或 Apple TV 上 Macdio 的「設定」裡啟動它，打開它顯示的位址，輸入 6 位數代碼，就會得到一張表格，可以新增、編輯、重新排序、匯入和匯出你的電台。沒有任何東西經過伺服器。瀏覽器只和你的裝置溝通。

Mac 沒有這個功能。在 Mac 上，你用「加入電台…」加入電台，按右鍵編輯它們，請看[加入自訂電台](/guides/add-a-custom-station.html)。

## 快速步驟

1. 在 iPhone 或 iPad 上，打開「設定」、「自訂電台」、「在電腦上編輯」。在 Apple TV 上，打開「設定」，移到「在電腦上編輯」卡片，選「打開」。
2. 啟動編輯器：按「啟動編輯器」，iPhone、iPad 和 Apple TV 上都是這個名稱。
3. 在電腦的瀏覽器裡，輸入裝置上顯示的位址。
4. 輸入 6 位數代碼。
5. 做好修改，按「Save」。

瀏覽器裡的頁面只有英文，所以下面瀏覽器裡的按鈕都保留英文名稱。

## 如何在 iPhone 或 iPad 上啟動編輯器

前往「設定」、「自訂電台」、「在電腦上編輯」（在 iPhone 上，「設定」放在「更多」裡，除非你把它移進了標籤列），點「啟動編輯器」。第一次使用時，iOS 會詢問是否允許 Macdio 尋找你區域網路上的裝置。請允許，否則瀏覽器連不到 iPhone 或 iPad。

執行後，「就緒」區塊會顯示「在你的電腦上打開」和位址，以及「接著輸入這組代碼」和用圓點隱藏的代碼，點「顯示」才會出現。「停止編輯器」會結束它。

## 如何在 Apple TV 上啟動編輯器

打開「設定」，移到「在電腦上編輯」卡片（「我的電台編輯器」），選「打開」。在「在電腦上編輯」畫面上，按「啟動編輯器」。

電視會顯示「打開此位址」和大字的位址，以及「然後輸入此代碼」和 6 位數字，數字一直都看得到。「停止編輯器」、「完成」或選單按鈕會關閉它。無法啟動時，會提供「重試」。

## 在瀏覽器裡能做什麼？

位址是一般的 http 位址，由裝置的 Wi-Fi 位址和一個連接埠號碼組成。連接埠每次啟動都會重新挑選，所以位址可能和上次不同，代碼每次啟動也都是新的。

頁面會先要求代碼。代碼錯誤時會顯示「That code did not work. Check the code on your device.」（代碼無效，請檢查裝置上的代碼）。

接著你會看到「My Stations」和電台數量，以及「Reload」（重新載入）和「Save」（儲存）。工具列有一個篩選欄位（依名稱、位址或標籤）、「Add station」（新增電台）、「Scan a website」（掃描網站）、「Import」（匯入）、「Export」（匯出），以及一個依名稱排序表格的按鈕。欄位依序是星號、Name、Stream URL、Logo URL、Country 和 Tags。

每一列都有一個拖移把手、一顆把電台設為收藏的星星、尋找標誌的「Logo」、請裝置檢查串流能否播放的「Test」（測試），以及移除這一列的「✕」。在小螢幕上，上下箭頭會取代拖移。兩列使用同一個位址時，頁面會用「Another row uses this same address」（另一列使用相同的位址）標出它們。

「Scan a website」使用和 App 相同的尋找功能：它會列出電台網站上的每個頻道和品質選擇器，「Add selected」（加入所選項目）會把它們放進表格。

各列的順序會成為 App 裡「我的電台」的順序。在你按「Save」之前，什麼都不會送到你的裝置，接著狀態會顯示「Saved to device」（已儲存到裝置）。從那裡開始，修改會透過 iCloud 同步到你的其他裝置。

## 如何從 JSON、CSV 或 M3U 匯入電台

「Import」接受你貼上的文字：

- JSON：一份電台清單，每個電台都有「name」和「streamURL」，也可以加上「logoURL」、「country」和「tags」。
- CSV：一行標題 `name,stream,logo,country,tags,favorite`，然後每行一個電台。
- M3U：一行帶著電台名稱的 `#EXTINF:-1,`，接著是串流位址。

「Fill with a JSON example」、「Fill with a CSV example」和「Fill with an M3U example」這三個按鈕會在框裡放入一份能用的範例。這是 M3U 的範例：

```
#EXTM3U
#EXTINF:-1,Radio Paradise
https://stream.radioparadise.com/aac-320
```

「Add to list」會把這些列加入表格。按「Save」時，它們才會送到裝置。

## 如何匯出你的電台

「Export」會在同一個畫面上，以 JSON、CSV 和 M3U 顯示你的電台，並提供「JSON file」、「CSV file」和「M3U file」。下載的檔案名稱是 macdio-stations.json、macdio-stations.csv 和 macdio-stations.m3u。

## 「Save」會對你的電台清單做什麼

「Save」會用頁面裡的表格取代你的自訂電台清單。你的裝置會保留你看到的列，刪除不在表格裡的每一個你的電台，iCloud 再把這個刪除帶到每部裝置。實際上：

- 你用「✕」移除的列，在儲存時會在每部裝置上被刪除，頁面不會先詢問。
- 如果這個頁面載入後，你在另一部裝置上新增或修改了電台，請在編輯前按「Reload」。從舊頁面儲存，會把舊的表格放回去。
- 每一列都要保留以 http:// 或 https:// 開頭的位址。位址是空的、或少了這個開頭的列，在儲存時會被捨棄，它所屬的電台也會被刪除。瀏覽器不會像 App 那樣替你加上「https://」。

## 編輯器什麼時候會停止？

它只在你保持打開時執行。你按下停止、離開編輯器畫面、Macdio 進入背景，或你關閉瀏覽器分頁時，它就會停止。瀏覽器 2 分鐘沒有動靜、5 分鐘內沒有瀏覽器連線，或代碼輸錯 5 次時，它也會停止。執行期間，手機或電視的螢幕會保持開啟。

## 值得知道的限制

- 兩部裝置必須在同一個網路上。
- 表格最多容納 500 個電台，一次只能執行一個網站掃描。
- 目錄裡的電台和你的清單不在編輯器裡。這些請在 App 裡修改，請看[收藏、清單和同步](/guides/favorites-lists-and-sync.html)。
- 這個頁面的 JSON 和 Mac 上「匯出電台…」的 JSON 是不同的格式。各自用自己的匯入功能讀回。

## 常見問題

### 哪些裝置有「在電腦上編輯」？

iPhone、iPad 和 Apple TV。Mac 本來就有鍵盤，直接在 App 裡編輯電台。Apple Watch 和 CarPlay 沒有這個功能。

### 為什麼我的電腦打不開那個位址？

兩部裝置必須在同一個 Wi-Fi 上，編輯器畫面必須保持打開，而在 iPhone 和 iPad 上，Macdio 需要區域網路權限。位址每次啟動都可能改變。

### 編輯器會更改目錄裡的電台嗎？

不會。瀏覽器裡只會出現你自己加入的電台，目錄裡的電台永遠不會被更改。

### 能匯入電台的 M3U 播放列表嗎？

可以。把播放列表的文字貼到「Import」，按「Add to list」，然後按「Save」。「Import」也接受 JSON 和 CSV。

### 在共用的 Wi-Fi 上使用編輯器安全嗎？

它需要一組每次啟動都會換新的 6 位數代碼，輸錯 5 次就會關閉，而且只在編輯器畫面打開時執行。連線是你網路內的一般 http。

### 我在瀏覽器裡移除的電台會怎樣？

一按「Save」，它就會在每部裝置上被刪除。「Save」會用頁面裡的表格取代你的自訂電台清單，所以如果你在別的地方改過電台，請先重新載入頁面。
