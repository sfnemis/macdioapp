iPhone、iPad、Macでは、どんなインターネットラジオ局でもストリームのアドレスでMacdioに追加できます。ライブラリで「+」をタップし、「カスタムステーションを追加」（Macでは「ステーションを追加…」）を選び、URLを貼り付けて、局に名前を付けて追加します。Macdioは保存する前に、そのアドレスが本当に音声を送っているかを確かめます。追加した局は、iCloudでApple TVを含むほかのデバイスに同期されます。

ディレクトリには60,000以上の局がありますが、それでも漏れている局があり、小さな地元の局が多いです。まだアドレスが分からないなら、[局のストリームURLを見つける方法](/guides/find-radio-stream-url.html)に探す場所を書いています。

## かんたんな手順

iPhoneかiPadで:

1. ライブラリを開いて「+」をタップします。
2. 「カスタムステーションを追加」を選びます。
3. 「ストリームアドレスまたはステーションのサイト」にアドレスを貼り付けます。
4. 「スキャン」をタップしてストリームを確認し、名前を入れてもらうか、「ステーション名」を自分で入力します。
5. 「追加」をタップします。

## 追加のボタンは、デバイスごとにどこにありますか？

| デバイス | 場所 | 保存するボタン |
|---|---|---|
| iPhoneとiPad | ライブラリ、「+」、「カスタムステーションを追加」、または設定、「カスタムステーション」、「カスタムステーションを追加」 | 「追加」 |
| Mac | ライブラリ、「+」、「ステーションを追加…」 | 「ステーションを追加」 |
| Apple TV | 設定、「コンピュータで編集」、そして同じWi-Fiにつながったブラウザ | ブラウザの「Save」 |
| Apple WatchとCarPlay | 追加のフォームはありません。ライブラリの局を再生します | |

iPhoneでは、タブバーに移していない限り、設定は「その他」の中にあります。

## iPhoneやiPadで局を追加する方法

「カスタムステーション」のシートで、「スキャン」（またはReturnキー）を押すと、「ストリームアドレスまたはステーションのサイト」に入力したものを確認します。ストリームなら確認が取れて、名前が空なら埋まります。ウェブサイトなら、そこにあるストリームの一覧が出て、それぞれに品質メニューと「使用」ボタンが付きます。「ロゴ」、「国」、カンマ区切りの「タグ」は入れなくても構いません。「ストリームURLをテスト」は、問題がなければ「ストリームに接続できます！」と答えます。名前かアドレスが空のあいだ、またはテストやスキャンの途中は、「追加」は灰色のままです。

## Macで局を追加する方法

ライブラリで「+」をクリックし、「ステーションを追加…」を選びます。「カスタムステーションを追加」のシートには、「ステーション名」、「スキャン」ボタン付きの「ストリームURL」、「ステーションのロゴ」、「国（任意）」、「タグ（カンマ区切り、任意）」があります。アドレスを入力すると「ストリームをテスト」が現れ、良いストリームならコーデックとビットレートと一緒に「Stream is reachable」と表示されます。「ステーションを追加」をクリックするか、Returnキーを押します。

## MacdioではどのストリームURLが使えますか？

- httpかhttpsで始まるアドレス。始まりを省くと、Macdioはまず「https://」を、次に普通の「http://」を試します。
- MP3とAACの直接のストリーム。
- HLSストリーム。.m3u8で終わるアドレスか、HLSのプレイリストを返すサーバーです。
- .pls、.m3u、.asx、.xspfで終わるプレイリストのリンク。Macdioはプレイリストを開き、最初のストリームを使います。
- SHOUTcastサーバー。「ICY 200 OK」と答える古いものも含みます。

ポッドキャストのエピソードやジングルのように長さの決まったファイルは、局として受け付けません。

## 「追加」をタップしたときにMacdioが確かめること

アドレスになり得ないものを入れると「Invalid URL format. Please check the URL.」（URLの形式が正しくありません）と出ます。同じ名前で同じアドレスの局がもう1つあると「A station with this name and URL already exists.」（同じ名前とURLの局がすでにあります）と出ます。

それからMacdioはサーバーに問い合わせ、最大6秒待ちます。アドレスがウェブサイトなら何も保存されず、スキャンが走るので、そこのストリームから1つを選べます。サーバーに接続できなければ、理由と「Tap Add again to save it anyway.」（Macでは「Click Add again to save it anyway.」）が表示されます。どちらも「もう一度押せばそのまま保存する」という意味で、もう一度タップすると保存されます。

新しい局は「マイステーション」の下に出ます。お気に入りになるのは、星を付けたときだけです（[お気に入り、リスト、同期](/guides/favorites-lists-and-sync.html)を見てください）。

## 自分で追加した局にロゴを付ける方法

「ロゴ」（Macでは「ステーションのロゴ」）には4つの選択肢があります:

- 「自動」は、局の名前とアドレスからLogo.devでロゴを探します。
- 「リンク」には、「画像アドレスをコピー」で手に入るような、.pngや.jpgで終わる画像ファイルへの直接のリンクを入れます。ロゴが載っているページを貼り付けても、Macdioが画像を見つけられれば差し替えます。
- 「自分の画像」は自分の画像を使います。iPhoneとiPadでは「写真」か「ファイル」（iCloud Driveも使えます）、Macでは「画像を選択…」です。画像は局と一緒に保存されるので、すべてのデバイスに表示されます。
- 「なし」はMacdio独自のアートワークを描きます。

あとで変えるには、iPhoneやiPadでは局を長押しし、Macでは右クリックして、「ステーションのロゴ…」を選びます。ディレクトリの局でも使え、そのときは「自動」、「自分の画像」、「なし」から選べます。「リンク」は自分で追加した局だけです。

## 自分で追加した局を編集、削除する方法

iPhoneとiPadでは、局を長押しして「ステーションを編集」を選ぶか、行を右にスワイプして「編集」をタップします。必要なところを変えて「保存」をタップします。削除するには、「マイステーション」でその行を左にスワイプし、「削除」をタップして、確認で「削除」を押します。確認には、局がすべてのデバイスから、入っているすべてのリストから消えることが書かれています。

Macでは、局を右クリックして「ステーションを編集」（そのあと「変更を保存」）か「ステーションを削除」を選びます。削除はこちらも先に確認を求めます。

編集を保存しても、変えたアドレスはテストされないので、先にテストのボタンを使ってください。ディレクトリの局は編集できませんが、「名前を変更…」（iPhoneとiPad）と「放送局の名称変更…」（Mac）で自分の呼び名を付けられ、「名前をリセット」で元の名前に戻ります。

## Apple TVで局を追加する

TVには追加のフォームがありません。TVの設定で「コンピュータで編集」を始めると、同じWi-Fiにつながったコンピュータのブラウザに、ロゴのURLも含めた自分の局の表が出ます（[手順はこちら](/guides/edit-stations-on-computer.html)）。もっとも、iPhone、iPad、Macで追加した局は、どのみちiCloudでTVに届きます。

## 知っておきたい制限

- 確認、スキャン、ロゴ探しはどれもネットにつながるので、局を追加するには接続が必要です。
- ウェブサイトのスキャンには最大1分かかることがあり、プレーヤーを巧妙に隠していてストリームが見つからないサイトもあります。
- iPhoneとiPadには、局の一覧をファイルから読み込む機能がありません。たくさんの局をまとめて入れるなら、[ブラウザのエディタ](/guides/edit-stations-on-computer.html)の「Import」を使ってください。
- CarPlayと[Siri](/guides/siri-radio.html)が自分で追加した局を見つけられるのは、お気に入りにしたか、最近再生した局になってからです。CarPlayはリストの中の局も表示します。

## よくある質問

### Macdioはどんなストリームのアドレスを受け付けますか？

httpかhttpsのラジオストリームならどれでも受け付けます。MP3、AAC、HLS（.m3u8）、.pls、.m3u、.asx、.xspfで終わるプレイリストのリンク、そして古いSHOUTcastサーバーです。ポッドキャストのエピソードは局として受け付けません。

### 局のウェブサイトしか分からないときは？

アドレス欄にウェブサイトを貼り付けて、「スキャン」を使ってください。Macdioがそこで見つけたストリームを品質メニュー付きで一覧にするので、1つを選びます。

### 「Tap Add again to save it anyway」と表示されるのはなぜですか？

アドレスを確認したときに、Macdioがストリームに接続できなかったからです。もう一度タップするとそのまま保存されます。局が一時的に止まっているだけのときに役立ちます。

### 自分で追加した局は、ほかのデバイスにも出ますか？

出ます。iCloudでMac、iPhone、iPad、Apple TVに同期され、Apple WatchはiPhoneから受け取ります。

### 自分で追加した局に独自のロゴを付けられますか？

付けられます。「自動」、「リンク」（画像のアドレス）、「自分の画像」（「写真」か「ファイル」の画像）、「なし」から選んでください。自分の画像はすべてのデバイスに表示されます。

## 試してみる

Macdioを[App Store](https://apps.apple.com/app/macdio/id6761737888)で手に入れて、ディレクトリにない1局を追加してみてください。1回の購入でiPhone、iPad、Mac、Apple TV、Apple Watchが使え、サブスクリプションはありません。
