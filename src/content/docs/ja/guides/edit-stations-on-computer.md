「コンピュータで編集」を使うと、自分で追加した局を、同じWi-Fiにつながったどのコンピュータのブラウザからでも、本物のキーボードで管理できます。iPhone、iPad、Apple TVのMacdioの設定で始め、表示されたアドレスを開き、6桁のコードを入力すると、局の追加、編集、並べ替え、読み込み、書き出しができる表が出ます。サーバーは一切通りません。ブラウザが話す相手はあなたのデバイスだけです。

Macにはこの機能はありません。Macでは「ステーションを追加…」で局を追加し、右クリックで編集します。[自分の局を追加](/guides/add-a-custom-station.html)を見てください。

## かんたんな手順

1. iPhoneかiPadでは、設定、「カスタムステーション」、「コンピュータで編集」を開きます。Apple TVでは設定を開き、「コンピュータで編集」のカードで「開く」を選びます。
2. エディタを始めます。iPhoneとiPadでは「エディタを開始」、Apple TVでも「エディタを開始」です。
3. デバイスに出ているアドレスを、コンピュータのブラウザに入力します。
4. 6桁のコードを入力します。
5. 変更をして「Save」をクリックします。

## iPhoneやiPadでエディタを始める方法

設定、「カスタムステーション」、「コンピュータで編集」と進み（iPhoneでは、タブバーに移していない限り設定は「その他」の中です）、「エディタを開始」をタップします。初回は、Macdioがローカルネットワーク上のデバイスを探してよいかをiOSが尋ねます。許可してください。許可しないと、ブラウザがiPhoneやiPadにつながりません。

動き出すと、「準備完了」の部分に「コンピュータで次を開きます」とアドレスが、「次にこのコードを入力します」とコードが出ます。コードは「表示」をタップするまで点で隠れています。「エディタを停止」で終わります。

## Apple TVでエディタを始める方法

設定を開き、「コンピュータで編集」のカード（「マイ放送局エディタ」）で「開く」を選びます。「コンピュータで編集」の画面で「エディタを開始」を押します。

TVには「このアドレスを開く」と大きな文字のアドレス、「次にこのコードを入力」と6桁の数字が、常に見える状態で出ます。「エディタを停止」、「完了」、Menuボタンのどれかで閉じます。始められなかったときは「再試行」が出ます。

## ブラウザでは何ができますか？

アドレスは、デバイスのWi-Fiのアドレスとポート番号でできた普通のhttpのアドレスです。ポートは起動のたびに選び直されるので、アドレスは前回と違うことがあり、コードも起動のたびに新しくなります。

ページは最初にコードを求めます。間違えると「That code did not work. Check the code on your device.」（コードが違います。デバイスのコードを確かめてください）と出ます。

そのあと、件数付きの「My Stations」と、「Reload」と「Save」が出ます。ツールバーには絞り込みの欄（名前、アドレス、タグで）、「Add station」、「Scan a website」、「Import」、「Export」、表を名前順に並べるボタンがあります。列は星、Name、Stream URL、Logo URL、Country、Tagsです。

ブラウザのページは英語で表示されます。各行には、ドラッグするための取っ手、局をお気に入りにする星、ロゴを探す「Logo」、ストリームが再生できるかデバイスに尋ねる「Test」、行を消す「✕」があります。小さな画面では、ドラッグの代わりに上下の矢印が出ます。2つの行が同じアドレスを使っていると、ページはそれに「Another row uses this same address」（ほかの行が同じアドレスを使っています）と印を付けます。

「Scan a website」はアプリと同じ仕組みで探します。局のサイトにあるすべてのチャンネルを品質の選択肢付きで一覧にし、「Add selected」で表に入れます。

行の順番が、アプリの「マイステーション」の順番になります。「Save」をクリックするまで、デバイスには何も届きません。クリックすると状態の表示が「Saved to device」になります。そこから変更がiCloudでほかのデバイスに同期されます。

## JSON、CSV、M3Uから局を読み込む方法

「Import」は貼り付けたテキストを受け付けます:

- JSON: 局のリストで、それぞれに「name」と「streamURL」、必要なら「logoURL」、「country」、「tags」を入れます。
- CSV: 見出しの行 `name,stream,logo,country,tags,favorite` のあとに、1行に1局ずつ。
- M3U: 局名の入った `#EXTINF:-1,` の行のあとに、ストリームのアドレス。

「Fill with a JSON example」、「Fill with a CSV example」、「Fill with an M3U example」のボタンで、そのまま使えるサンプルが欄に入ります。M3Uのサンプルはこれです:

```
#EXTM3U
#EXTINF:-1,Radio Paradise
https://stream.radioparadise.com/aac-320
```

「Add to list」で行が表に加わります。デバイスに届くのは「Save」をクリックしたときです。

## 局を書き出す方法

「Export」は局をJSON、CSV、M3Uで1つの画面に表示し、「JSON file」、「CSV file」、「M3U file」のダウンロードを用意します。ファイル名はmacdio-stations.json、macdio-stations.csv、macdio-stations.m3uです。

## 「Save」が局の一覧に何をするか

「Save」は、カスタムステーションの一覧をページの表で置き換えます。デバイスは表に見えている行を残し、表にない自分の局をすべて削除し、iCloudがその削除をすべてのデバイスに運びます。実際には:

- 「✕」で消した行は、保存したときにすべてのデバイスから削除されます。ページは先に確認しません。
- このページを読み込んだあとに、ほかのデバイスで局を追加したり変えたりしたなら、編集の前に「Reload」をクリックしてください。古いページから保存すると、古い表が戻ってきます。
- どの行にも、http:// か https:// で始まるアドレスを残してください。アドレスが空の行や、その始まりがない行は保存時に捨てられ、その行の局は削除されます。ブラウザは、アプリのように「https://」を補ってはくれません。

## エディタはいつ止まりますか？

開いているあいだだけ動きます。停止を押したとき、エディタの画面を離れたとき、Macdioがバックグラウンドに回ったとき、ブラウザのタブを閉じたときに止まります。ブラウザから2分間何もないとき、5分以内にどのブラウザもつながらないとき、コードを5回間違えたときにも止まります。動いているあいだ、電話やTVの画面は消えません。

## 知っておきたい制限

- 両方のデバイスが同じネットワークにある必要があります。
- 表には最大500局まで入り、ウェブサイトのスキャンは一度に1つです。
- ディレクトリの局とリストはエディタに出ません。それらはアプリで変えてください。[お気に入り、リスト、同期](/guides/favorites-lists-and-sync.html)を見てください。
- このページのJSONと、Macの「ステーションをエクスポート…」のJSONは形式が違います。それぞれ、対応する読み込みで戻してください。

## よくある質問

### 「コンピュータで編集」があるのはどのデバイスですか？

iPhone、iPad、Apple TVです。Macにはもともとキーボードがあるので、局はアプリの中で編集します。Apple WatchとCarPlayにはありません。

### コンピュータでアドレスが開けないのはなぜですか？

両方のデバイスが同じWi-Fiにつながっていること、エディタの画面が開いたままであること、iPhoneとiPadではMacdioにローカルネットワークの許可があることが必要です。アドレスは起動するたびに変わることがあります。

### エディタでディレクトリの局が変わることはありますか？

ありません。ブラウザに出るのは自分で追加した局だけで、ディレクトリの局が変わることはありません。

### 局のM3Uプレイリストを読み込めますか？

読み込めます。「Import」にプレイリストのテキストを貼り付け、「Add to list」をクリックしてから「Save」を押します。「Import」はJSONとCSVも受け付けます。

### 共有のWi-Fiでもエディタは安全ですか？

起動のたびに新しくなる6桁のコードが必要で、5回間違えると閉じ、エディタの画面が開いているあいだしか動きません。接続はネットワーク内の普通のhttpです。

### ブラウザで消した局はどうなりますか？

「Save」をクリックした時点で、すべてのデバイスから削除されます。「Save」はカスタムステーションの一覧をページの表で置き換えるので、ほかの場所で局を変えたなら、先にページを再読み込みしてください。

## 試してみる

Macdioを[App Store](https://apps.apple.com/app/macdio/id6761737888)で手に入れて、局をいくつか追加したら、iPhone、iPad、Apple TVで「コンピュータで編集」を開いてみてください。1回の購入で、すべてのAppleデバイス、サブスクリプションなしです。
